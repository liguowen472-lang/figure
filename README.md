# 测测你是哪位历史人物

纯静态网页，没有依赖，不需要构建。

## 部署到 GitHub Pages
1. 新建仓库，把本文件夹里的所有文件上传到仓库根目录（保留 `assets/` 文件夹）。
2. 进入仓库的 Settings → Pages，Source 选 `Deploy from a branch`，Branch 选 `main` / `(root)`，然后保存。
3. 等 1–2 分钟，访问 `https://你的用户名.github.io/仓库名/`。

## 文件说明
- `index.html`：页面结构
- `style.css`：样式，手机优先，桌面端是双栏布局
- `data.js`：12 道题、4 个维度、16 位人物的文案（改文案只需要改这个文件）
- `app.js`：答题、计分、结果页、分享卡和分享链接
- `assets/mountains.jpg`：水墨山水图

## 计分规则
每个维度 3 道题，每个选项计 +2 / +1 / -1 / -2 分。总分为正取前一个字母，为负取后一个字母；总分为 0 时，按该维度最后一题的方向决定。
维度依次是：锋芒A/隐忍B，谋略C/性情D，合群E/独行F，入世G/出世H。

## 分享链接
`?r=BDEG&p=40-30-70-60` 直接打开好友的结果页。如果访问者自己测过，页面会显示两人在几个维度上相同。
